THIẾT LẬP FIREBASE TRƯỚC KHI DEPLOY
1. Firebase Console > Authentication > Sign-in method: bật Email/Password.
2. Authentication > Users: bảo đảm có adminnamhoa@gmail.com với UID:
   N1tXsaexgfNlqjsanViPvEBXZxJ3
3. Realtime Database > Rules: dán firebase-database.rules.json rồi Publish.
4. Không bắt buộc import dữ liệu: lần đăng nhập đầu ứng dụng tự tạo users/{UID}.
   Nếu tự tạo không thành công, vào Realtime Database > Data > Import JSON và chọn
   firebase-initial-data.json.
5. Không cần tạo/deploy Firebase Storage hoặc Firebase Functions.
6. Deploy thư mục này bằng Cloudflare Worker/Pages. wrangler.jsonc đã trỏ worker.js
   và static assets, không cần Firebase Hosting.
7. Authentication > Settings > Authorized domains: thêm domain triển khai mới.
